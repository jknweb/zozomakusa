Thème bloc du traiteur événementiel ZozoMakusa (Kinshasa). Tout se modifie dans l'éditeur de site, sans extension.

== Description ==

Accueil composé de motifs : ouverture « ligne de buffet », occasions servies, carte des formules,
déroulé d'une commande, galerie « Sur nos tables » avec étiquettes de plats, appel au devis WhatsApp.

Tous les boutons « Devis WhatsApp » utilisent le numéro réglé dans Réglages › Général › Numéro WhatsApp.
Dans l'éditeur, un lien vers « #whatsapp » devient automatiquement ce lien WhatsApp.

Styles propres au thème : image « Cloche », galerie « Étiquettes de buffet », groupe « Carte de menu »,
liste « Liste à filets », sections « Nuit », « Feuille » et « Sauge ».

Voir GUIDE-UTILISATION.md pour la prise en main.
